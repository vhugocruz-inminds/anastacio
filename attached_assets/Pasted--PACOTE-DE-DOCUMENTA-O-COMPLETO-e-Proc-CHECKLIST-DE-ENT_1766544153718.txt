### **C. Coding Standards**

```markdown
# Coding Standards - e-Proc

## TypeScript

### Naming Conventions
- **Files**: kebab-case (e.g., `supplier.service.ts`)
- **Classes**: PascalCase (e.g., `SupplierService`)
- **Interfaces**: PascalCase with 'I' prefix (e.g., `ISupplier`)
- **Functions/Methods**: camelCase (e.g., `createSupplier()`)
- **Constants**: UPPER_SNAKE_CASE (e.g., `MAX_FILE_SIZE`)
- **Private members**: prefix with _ (e.g., `_validateCNPJ()`)

### Code Style
- Use async/await instead of promises
- Always use TypeScript strict mode
- No 'any' type (use 'unknown' if needed)
- Prefer const over let
- Use arrow functions for callbacks
- Maximum line length: 100 characters

### Example
```typescript
// Good
export class SupplierService {
  private readonly logger = new Logger(SupplierService.name);
  
  constructor(
    private readonly prisma: PrismaService,
    private readonly proteusService: ProtheusService,
  ) {}
  
  async createSupplier(dto: CreateSupplierDto): Promise<Supplier> {
    this.logger.log('Creating supplier', { cnpj: dto.cnpj });
    
    // Validate CNPJ
    const isValid = await this.validateCNPJ(dto.cnpj);
    if (!isValid) {
      throw new BadRequestException('Invalid CNPJ');
    }
    
    // Create in database
    const supplier = await this.prisma.supplier.create({
      data: dto,
    });
    
    // Sync with Protheus
    await this.proteusService.createSupplier(supplier);
    
    return supplier;
  }

  }
}
