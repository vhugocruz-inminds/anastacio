# 🚀 EXPERT DEVELOPMENT PROMPT: e-Proc (e-Procurement System)

**Project:** e-Proc - Sistema de E-Procurement B2B para Química Anastácio  
**Target Platform:** Replit.com  
**Development Mode:** Full-Stack TypeScript/Node.js  
**Client:** Química Anastácio (https://anastacio.com/)  
**Deadline:** 16 semanas (4 meses)  

---

## 🎯 PROJECT OVERVIEW

You are tasked with building **e-Proc**, a comprehensive B2B e-procurement platform that automates the complete procurement cycle from supplier registration to payment (Procure-to-Pay). This system will replace manual processes and integrate with existing ERP systems (TOTVS Protheus, Protheus-EIC) and BPM platform (Fluig).

**Key Business Goals:**
- Reduce procurement lead time by 40%
- Reduce operational costs by 25%
- Achieve 15% savings through better negotiations
- 100% digitalization of processes
- Full auditability and compliance

---

## 🏗️ TECHNICAL ARCHITECTURE

### **Stack Specification**

**Backend:**
- **Runtime:** Node.js 20+ LTS
- **Framework:** NestJS (TypeScript)
- **ORM:** Prisma (PostgreSQL + MongoDB)
- **API:** REST + GraphQL (optional for complex queries)
- **Authentication:** JWT + OAuth 2.0 + MFA
- **Message Queue:** RabbitMQ or Kafka
- **Cache:** Redis
- **Search:** ElasticSearch (product catalog)

**Frontend:**
- **Framework:** React 18+ with TypeScript
- **State Management:** Zustand or Redux Toolkit
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **Forms:** React Hook Form + Zod validation
- **Data Fetching:** TanStack Query (React Query)
- **Charts:** Recharts
- **Tables:** TanStack Table

**Mobile (Future Phase):**
- React Native or Flutter

**Database:**
- **Primary:** PostgreSQL 15+ (transactional data)
- **Secondary:** MongoDB (product catalogs, flexible schemas)
- **Cache:** Redis (sessions, frequently accessed data)
- **Search:** ElasticSearch (full-text search)

**Infrastructure (Replit):**
- Start with Replit's Node.js template
- Use Replit Database for development
- Plan for future migration to AWS/Azure
